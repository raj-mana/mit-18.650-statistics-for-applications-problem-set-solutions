# Problem Set Solutions for MIT 18.650 Statistics for Applications, Fall 2016
These are personal problem set solutions for the MIT course 18.650 Statistics for Applications, Fall 2016, available on MIT OpenCourseWare. Problem sets are posted [here](https://ocw.mit.edu/courses/18-650-statistics-for-applications-fall-2016/pages/assignments/). This course covers theoretical foundations for statistical methods that are useful in many applications, with topics as follows:
1.	Introduction to Statistics
2.	Parametric Inference
3.	Maximum Likelihood Estimation
4.	The Method of Moments
5.	Parametric Hypothesis Testing
6.	Testing Goodness of Fit
7.	Regression
8.	Bayesian Statistics
9.	Principal Component Analysis
10.	Generalized Linear Models
